## ⭐ Overview
Lab 07 introduced me to the basic ideas behind machine learning. Instead of building a full model, this lab focused on understanding how machine learning works, what data it needs, and how algorithms learn patterns. It was a beginner-friendly way to connect earlier labs to the bigger picture of AI.

## 🛠️ What I Did
- Reviewed key machine learning terms  
- Explored examples of supervised and unsupervised learning  
- Looked at how models use data to make predictions  
- Practiced identifying features and labels in a dataset  
- Completed small exercises to reinforce the concepts  

## 📘 What I Learned
- The difference between supervised and unsupervised learning  
- What features and labels are  
- How training data helps a model learn  
- Why machine learning depends on clean, organized data  
- How simple models make predictions based on patterns  

## ⚡ Challenges
The main challenge was understanding how models “learn” without being explicitly programmed. Breaking the process into steps made it easier to understand how data guides the model.

## 🎯 Summary
Lab 07 helped me build a foundation for machine learning by explaining how models learn from data and make predictions. These concepts prepare me for future labs where I will build and test actual machine learning models.
