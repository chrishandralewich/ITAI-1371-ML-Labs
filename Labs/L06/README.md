##  Overview
Lab 06 focused on basic data cleaning techniques. This lab helped me understand how to prepare a dataset by fixing common issues like missing values, duplicates, and inconsistent formatting. Clean data is essential for any machine learning project, so this lab was an important step in learning how to work with real-world datasets.

##  What I Did
- Loaded a dataset into a Jupyter Notebook  
- Identified missing values  
- Removed or filled in incomplete data  
- Checked for duplicate rows  
- Fixed simple formatting issues  
- Practiced using pandas functions for cleaning  

##  What I Learned
- Why data cleaning is necessary before analysis  
- How to detect missing or incorrect data  
- How to use pandas tools like `dropna()`, `fillna()`, and `drop_duplicates()`  
- How clean data improves model accuracy  
- How small mistakes in data can affect results
