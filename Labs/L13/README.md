# L13 — Deep Learning Practice with MNIST
### Chrishandra Lewich — ITAI 1371

##  Overview
Lab 13 focused on building and training a neural network using the MNIST dataset, which contains handwritten digits from 0–9. This lab helped me understand how deep learning models work on real image data and how training improves accuracy over time. It was a hands-on way to apply neural network concepts from earlier labs.

##  What I Did
- Loaded the MNIST dataset  
- Preprocessed the images for training  
- Built a neural network model with multiple layers  
- Trained the model using training data  
- Evaluated accuracy using test data  
- Visualized predictions and results  

##  What I Learned
- How to prepare image data for deep learning  
- How neural networks process pixel values  
- How training over multiple epochs improves accuracy  
- How to interpret model predictions  
- Why MNIST is a common beginner dataset for learning deep learning  

##  Challenges
The main challenge was understanding how different layer choices affected accuracy. Experimenting with the number of layers and activation functions helped me see how architecture impacts performance.

##  Summary
Lab 13 helped me apply deep learning concepts by training a neural network on the MNIST dataset. This lab strengthened my understanding of image processing, neural network structure, and model evaluation.
