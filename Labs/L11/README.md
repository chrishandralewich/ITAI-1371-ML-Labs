# L11 — Model Improvement and Tuning
### Chrishandra Lewich — ITAI 1371

##  Overview
Lab 11 focused on improving a machine learning model by adjusting settings, trying different algorithms, and testing how changes affect performance. This lab helped me understand that machine learning is not just about building a model — it’s about tuning and experimenting to make the model better.

##  What I Did
- Trained a baseline machine learning model  
- Adjusted model parameters to see how performance changed  
- Tested different algorithms for comparison  
- Evaluated results using accuracy and other metrics  
- Practiced making small, controlled changes to improve the model  

##  What I Learned
- How tuning parameters can improve model performance  
- Why different algorithms behave differently on the same dataset  
- How to compare models fairly using evaluation metrics  
- How small adjustments can make a big difference  
- Why experimentation is a key part of machine learning  

##  Challenges
The main challenge was understanding which parameters mattered most. It took some trial and error to see how each change affected the model’s accuracy and behavior.

##  Summary
Lab 11 helped me learn how to improve machine learning models through tuning and experimentation. These skills are essential for building stronger, more accurate models in future labs and assignments.
