# L10 — Feature Engineering Basics
### Chrishandra Lewich — ITAI 1371

##  Overview
Lab 10 introduced me to feature engineering, which is the process of improving a dataset so a machine learning model can learn more effectively. This lab helped me understand how to create new features, transform existing ones, and prepare data in a way that makes patterns easier for a model to detect.

##  What I Did
- Explored the dataset to identify useful features  
- Created new features from existing data  
- Transformed or scaled certain values  
- Removed features that were not helpful  
- Compared model performance before and after feature changes  

##  What I Learned
- What feature engineering is and why it matters  
- How new features can reveal patterns that weren’t visible before  
- How transformations (like scaling or encoding) help models learn  
- How removing unnecessary features can improve accuracy  
- How feature choices affect the final model’s performance  

##  Challenges
The main challenge was deciding which features were actually useful. It took some trial and error to see how different changes affected the model’s results.

##  Summary
Lab 10 helped me understand how to improve a dataset through feature engineering. These skills are important for building stronger machine learning models and will be used in future labs and assignments.
