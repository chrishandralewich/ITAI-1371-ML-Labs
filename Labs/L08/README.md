## ⭐ Overview
Lab 08 was my first hands-on experience building a simple machine learning model. This lab helped me understand how data is split into training and testing sets, how a model learns patterns, and how to evaluate its performance. It was a beginner-friendly introduction to actually training a model instead of just learning concepts.

## 🛠️ What I Did
- Loaded a dataset into a Jupyter Notebook  
- Split the data into training and testing sets  
- Selected a basic machine learning algorithm  
- Trained the model using the training data  
- Made predictions on the test data  
- Calculated accuracy to see how well the model performed  

## 📘 What I Learned
- How to prepare data for machine learning  
- Why training and testing sets are important  
- How a model “learns” from patterns in the data  
- How to evaluate model performance using accuracy  
- How small changes in data or settings can affect results  

## ⚡ Challenges
The main challenge was understanding how the train/test split affects accuracy. Once I saw how the model behaved with different splits, the process made much more sense.

## 🎯 Summary
Lab 08 helped me take my first real step into machine learning by training a simple model and evaluating its performance. This lab built a strong foundation for future labs where I will work with more advanced algorithms and techniques.
