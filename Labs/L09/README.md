# L09 — Evaluating Model Performance
### Chrishandra Lewich — ITAI 1371

## ⭐ Overview
Lab 09 focused on understanding how to evaluate a machine learning model after it has been trained. This lab helped me learn why accuracy alone is not always enough, and how different evaluation metrics can give a clearer picture of how well a model is performing. It was a beginner-friendly introduction to model evaluation techniques.

## 🛠️ What I Did
- Trained a simple machine learning model  
- Used the model to make predictions  
- Calculated accuracy to measure performance  
- Explored additional evaluation metrics  
- Compared results to understand strengths and weaknesses  

## 📘 What I Learned
- Why evaluation is an important part of machine learning  
- How accuracy works and when it can be misleading  
- How to interpret other metrics like precision, recall, or confusion matrices  
- How evaluation helps identify model errors  
- How to think critically about model results instead of relying on one number  

## ⚡ Challenges
The main challenge was understanding what each metric meant and how they relate to real-world performance. Once I broke down each metric step-by-step, the results became much easier to understand.

## 🎯 Summary
Lab 09 helped me learn how to evaluate machine learning models using more than just accuracy. These skills are essential for understanding whether a model is truly performing well and for improving future models.
