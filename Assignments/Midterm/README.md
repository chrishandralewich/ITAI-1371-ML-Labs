# Midterm — Machine Learning Skills Demonstration
### Chrishandra Lewich — ITAI 1371

##  Overview
The Midterm assignment demonstrated my understanding of core machine learning concepts covered in the first half of the course. This included data exploration, cleaning, model building, evaluation, and reflection. The goal was to show that I could apply the full workflow of a basic machine learning project.

##  What I Did
- Loaded and explored the dataset  
- Cleaned and prepared the data for modeling  
- Selected an appropriate machine learning algorithm  
- Split the data into training and testing sets  
- Trained the model and made predictions  
- Evaluated performance using accuracy and other metrics  
- Reflected on results and explained my process  

##  What I Learned
- How to apply the full machine learning pipeline  
- How data quality affects model performance  
- How to choose and justify a model  
- How to interpret evaluation metrics  
- How to communicate results clearly and professionally  

##  Challenges
The main challenge was balancing accuracy with simplicity. I learned that a “better” model isn’t always the most complex one — it’s the one that fits the data and the assignment goals.

##  Summary
The Midterm showed my ability to complete a full machine learning workflow from start to finish. It strengthened my confidence in building, evaluating, and explaining machine learning models.
